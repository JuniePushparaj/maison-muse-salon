# Maison Muse Salon

A responsive static salon website concept for a salon in Chennai.

## Deploy with Netlify
1. Sign in to Netlify.
2. Choose **Add new site → Import an existing project**.
3. Connect GitHub and select `JuniePushparaj/maison-muse-salon`.
4. Leave the build command empty and set the publish directory to `.`.
5. Deploy the site.

## Before using for a real business
Replace the demo WhatsApp number, address, opening hours, social handle, and service prices with the salon's actual details.

This site uses HTML and CSS only. Images and Google Fonts are loaded from external services.
